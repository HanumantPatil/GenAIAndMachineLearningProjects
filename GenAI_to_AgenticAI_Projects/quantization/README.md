## Overview

The notebook demonstrates basic numeric quantization concepts with NumPy and
Matplotlib visualizations.

## Setup

Run these commands from this folder:

```powershell
uv venv .venv
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
```

## Run

```powershell
.\.venv\Scripts\jupyter.exe lab quantization_basic.ipynb
```
