## Overview

These notebooks demonstrate LangChain CSV and URL document loaders. URL loading
requires internet access and depends on the target site's access policy.

## Setup

Run these commands from this folder:

```powershell
uv venv .venv
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
```

## Run

```powershell
.\.venv\Scripts\jupyter.exe lab
```
