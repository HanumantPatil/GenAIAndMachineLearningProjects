## CodeApp

This folder contains C# practice code across design patterns, low-level design, and algorithm examples.

## What Changed

* Updated the summary to reflect broader pattern and LLD coverage
* Refreshed run and build commands

## Contents

* `Program.cs`: Entry point with sample algorithm logic (`isSubSequence`).
* `ArrayConcatenation.cs`: Array-related practice implementation.
* `MedianOfTwoSortedArrays.cs`: Median-of-two-sorted-arrays practice implementation.
* `example.cs`: Additional experimentation file.

## Prerequisites

* .NET SDK 8.0 or later

## Run

```bash
dotnet run --project CodeApp.csproj
```

## Build

```bash
dotnet build CodeApp.csproj
```
